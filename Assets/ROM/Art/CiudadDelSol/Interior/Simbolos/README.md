# Biblioteca común de símbolos
Cuatro prefabs distintos: advertencia roja, investigación verde, corrupción violeta y contención azul.
Las asociaciones de color son convenciones visuales propuestas, no hechos históricos confirmados.
URP Lit opaco; emisión 1,4; contorno oscuro para contraste sin Bloom. No modifica iluminación ni postprocesado global.
Prefabs normalizados en plano XY, frente -Z, sin colliders, luces ni scripts de gameplay.
Las variantes Proyectado se ajustan a las superficies reales de A03/R21. No usar sus coordenadas como prefabs genéricos.
