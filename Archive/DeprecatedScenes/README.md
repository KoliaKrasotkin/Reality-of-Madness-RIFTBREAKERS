# Escenas deprecadas

Este directorio está fuera de Assets: Unity no importa estas escenas.
Contiene nueve escenas antiguas y el catálogo de pruebas, con sus .meta.
La estructura conserva la ruta original bajo Assets para poder recuperarlas.

Para restaurar una escena concreta, mover su archivo y su .meta a su ruta
original dentro del proyecto con Unity cerrado. No sobrescribir una escena
activa ni restaurar todo el directorio indiscriminadamente.

Ver Documentation/scene-cleanup.txt y Documentation/SCENES.md.
